# Moving Your Body

A browser-based movement game for children. The four large colored squares show hand and foot symbols. The game advances automatically; it does not use a camera or check whether movements are performed correctly.

## Run locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Choose **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. After publishing, the game will be available at `https://jb1111111111.github.io/Moving-Your-Body/`.

## Game modes
- Easy: feet only, starting with one and sometimes two.
- Medium: hands are introduced after the opening rounds.
- Hard: hands and feet are mixed, with a maximum of two hands and two feet.
- Time, Set, and Unlimited modes.
- Optional sound effects; no spoken instructions.
